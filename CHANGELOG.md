# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [3.0.0.0] 

### Added
- **Atlas Cardano SDK Integration**: Complete migration to Atlas Cardano SDK for enhanced performance and reliability
- **REST API**: Full-featured REST API with Swagger documentation
- **WebSocket Support**: Real-time updates via Server-Sent Events
- **Comprehensive Testing**: Extensive unit and property test suite
- **PureScript Bridge**: Automated code generation for frontend integration
- **Docker Support**: Production-ready Docker configuration
- **Enhanced Development Tools**: Improved Nix integration and development workflow
- **Interactive API Documentation**: Swagger UI for API exploration

### Changed
- **Dependencies**: Updated to latest Cardano libraries and tools
- **Documentation**: Comprehensive documentation updates and improvements

### Fixed
- **Performance**: Optimized transaction building and submission
- **Reliability**: Enhanced error handling and recovery mechanisms

### Technical Details
- **GHC Version**: 9.6.6
